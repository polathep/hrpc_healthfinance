# ต้นทุนบริการโรงพยาบาลสงขลานครินทร์ ปีงบประมาณ 2567

แดชบอร์ดนี้สรุปต้นทุน ค่ารักษา และความน่าเชื่อถือของข้อมูลสำหรับผู้บริหาร ตัวเลขมาจากโครงการศึกษาต้นทุนโรงพยาบาลสงขลานครินทร์ คณะแพทยศาสตร์ มหาวิทยาลัยสงขลานครินทร์ ปีงบประมาณ 2567 (1 ต.ค. 2566 – 30 ก.ย. 2567)

**สร้างโดย Polathep Vichitkunakorn** · จัดทำ 23 กันยายน 2569

## เนื้อหาในแดชบอร์ด

| แท็บ | เนื้อหา |
|---|---|
| ภาพรวม | ตัวชี้วัดหลัก ประเด็นสำคัญ การไหลของต้นทุน และ RCC แต่ละระดับ |
| โครงสร้างต้นทุน | ค่าแรง ค่าวัสดุ ค่าลงทุน แยกตามประเภทหน่วยต้นทุน (ACC/DCC/OCC/TCC) และช่องค้นหาหน่วยต้นทุน |
| ต้นทุนเทียบค่ารักษา | RCC รายหมวดค่ารักษา หมวดย่อย (BSub) และรายการบริการทั้ง 9,076 รายการ |
| ผู้ป่วยนอก | ต้นทุนต่อครั้ง แยกตามสิทธิ คลินิก และรหัสโรค (ICD-10) |
| ผู้ป่วยใน | ต้นทุนต่อราย แยกตามสิทธิ กลุ่มโรคใหญ่ (MDC) DRG และหอผู้ป่วย |
| เทียบ UHosNet | เปรียบเทียบกับโรงพยาบาลในกลุ่มสถาบันแพทยศาสตร์ กลุ่ม L / M / S |
| ตรวจทานข้อมูล | ผลการตรวจความถูกต้อง 33 รายการ ระดับความเชื่อมั่นตามการใช้งาน และการกระทบยอดระหว่างไฟล์ข้อมูลกับรายงาน |
| นิยามและที่มา | อภิธานศัพท์ วิธีคำนวณต้นทุน และรายการแหล่งข้อมูล |

## ที่มาของข้อมูล

- **ไฟล์ข้อมูล DT01–DT08:** จัดทำโดยสำนักพัฒนากลุ่มโรคร่วมไทย (สรท., Thai CaseMix Centre) ฉบับ 20 ส.ค. 2569 ใช้เป็นตัวเลขหลัก ในหน้าแดชบอร์ดมีป้าย **ข้อมูล** กำกับ
- **รายงาน PSU01, PSU02, PSU10, PSU11, PSU12:** จัดทำโดย สรท. และสถาบันวิจัยระบบสาธารณสุข (สวรส.) เดือน ก.ค. 2569 ใช้เป็นค่าอ้างอิง ในหน้าแดชบอร์ดมีป้าย **รายงาน** กำกับ
- **ข้อมูลพื้นฐานโรงพยาบาล:** มาจากงานนโยบายและแผน โรงพยาบาลสงขลานครินทร์

## ข้อควรทราบ

- **ค่ารักษา (charge) ไม่ใช่รายรับจริง:** เป็นราคาตามบัญชีราคาของโรงพยาบาล RCC จึงบอกความสมดุลระหว่างต้นทุนกับราคา ไม่ได้บอกกำไรหรือขาดทุนทางบัญชี
- **ไฟล์ข้อมูลเป็นฉบับปรับปรุงหลังการนำเสนอ:** ตัวเลขบางตัวจึงต่างจากรายงาน ส่วนต่างทั้งหมดแสดงไว้ในแท็บ "ตรวจทานข้อมูล"
- **ประเด็นที่ควรยืนยันกับ สรท. ก่อนนำไปใช้ตัดสินใจ:**
  - ต้นทุนหน่วยสนับสนุน 99 ลบ. ยังไม่ถูกจัดสรร
  - ในรายงาน PSU12 ข้อมูลผู้ป่วยนอกสิทธิข้าราชการ (CS) กับประกันสังคม (SS) สลับแถวกัน
  - กลุ่มเทียบ M น่าจะรวม มอ. อยู่ด้วย
- **การตีความในแดชบอร์ดเป็นความเห็นของผู้จัดทำ:** ไม่ใช่ข้อสรุปอย่างเป็นทางการของ สรท. หรือโรงพยาบาล
